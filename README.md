# Artrium | Creative Artwork Showcase Platform 🎨

Artrium is a modern, full-stack web application designed for artists to showcase their creativity. Users can upload artworks, explore global galleries, like their favorite pieces, and manage their personal art collections in a seamless, dark/light mode environment.

## 🌐 Live Links
- **Primary Domain:** [https://artrium-tourmaline.netlify.app/](https://artrium-tourmaline.netlify.app/)
- **Firebase Mirror:** [https://artrium-b059f.web.app/](https://artrium-b059f.web.app/)

## ✨ Key Features
- **Dynamic Art Gallery:** Explore a wide range of public artworks with advanced searching by title/artist and filtering by categories using a sleek tab system.
- **Personalized Experience:** Logged-in users can curate their own "My Gallery" with full CRUD (Create, Read, Update, Delete) capabilities.
- **Interaction System:** Appreciate fellow artists by liking their work and adding masterpieces to a dedicated "My Favorites" list.
- **Adaptive UI:** Fully responsive design featuring a persistent Dark/Light mode toggle and smooth animations powered by React Awesome Reveal.
- **Secure Authentication:** Integrated Firebase Authentication with Google Social Login and Email/Password validation.

## 🛠️ Technologies Used
- **Frontend:** React.js, Tailwind CSS, DaisyUI
- **Routing:** React Router 7
- **State & Logic:** Context API, Axios, Framer Motion
- **Animations & UI:** React Awesome Reveal, React Toastify, SweetAlert2
- **Backend Integration:** Vercel-hosted Express.js API

## 🚀 Installation & Local Setup
1. Clone the repo: `git clone https://github.com/nozibuddowla/artrium-client.git`
2. Install dependencies: `npm install`
3. Create a `.env.local` file and add your Firebase config.
4. Run locally: `npm run dev`
